# 1.0.0 licensing review

The runtime uses the independent Nth page deck, with no Turn.js or jQuery dependency. Obsolete CDN precache entries were removed. Third-party JavaScript remains in use; THIRD_PARTY_NOTICES.txt includes upstream licenses for JSZip (MIT option), html2canvas, PDF.js and the inventoried embedded dependencies. Conservative adapter notices are included without claiming exact nested versions.

Four font families with reserved-name declarations were removed as requested. All 17 retained font license preambles were reviewed. Full license texts are bundled, and the app exposes them offline through Licenses & Credits. Six newly converted regular faces preserve full upstream glyph coverage.

This is a technical inventory, not a blanket commercial clearance. Brad has confirmed the project artwork was created with the assistant; see ARTWORK_PROVENANCE.md. App-store terms, privacy disclosures, and production signing are separate release requirements.
