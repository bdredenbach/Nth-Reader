# Artwork provenance — 1.0.0

Brad Redenbach confirms that the project artwork was created with the assistant during this project's development, including the original bookshelf reference and Nth logo. This is the owner's provenance confirmation; it supersedes the unresolved-origin notes from the recovery audit.

The splash and empty shelf images were generated for this project from the bookshelf and decor references. The splash interprets those decoration references while the live shelves use the independently movable catalog assets. The Nth logo is overlaid separately. Existing reader textures, decoration catalog, and widget imagery are retained from the tested 0.38.13 candidate.

This records the supplied history, rather than asserting exclusive rights over every generated element or providing third-party trademark clearance. Third-party software and font licenses remain in THIRD_PARTY_NOTICES.txt.
